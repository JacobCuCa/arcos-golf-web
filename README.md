# Arcos Golf by Patiño Resorts · Web

Webs públicas de **Arcos Golf by Patiño Resorts** (Arcos de la Frontera, Cádiz), servidas con GitHub Pages.

| Ruta | Web |
|---|---|
| `/` | Índice de las cuatro webs |
| `/dossier/` | Dossier conjunto: inversión + experiencia, con todos los PDFs |
| `/investors/` | Línea inversores |
| `/holidays/` | Línea comercial / promocional |
| `/experience/` | Experience Book online |

Las páginas llevan `noindex` y `robots.txt` bloquea a los buscadores: solo llega quien tenga el enlace.

El material de trabajo (textos del cliente, fuentes, notas, fotos originales) está en el repositorio privado `arcos-golf`. Esta copia solo contiene lo publicable; para actualizarla se copia `arcos-golf/web/` aquí.
